## 👩‍💻 Sobre esta experiencia

Este repositorio reúne parte del material, ejercicios y trabajos realizados durante mi formación en programación con **Egg Cooperation**, en el marco de **Argentina Programa 4.0**.

Fue una experiencia de aprendizaje online, compartida con distintos compañeros y grupos de trabajo, donde fui incorporando conocimientos y desarrollando habilidades de manera progresiva.

El recorrido comenzó desde los fundamentos de la lógica de programación y avanzó hacia el desarrollo de software, las bases de datos y la programación orientada a objetos.

A lo largo de esta formación pude experimentar cómo evolucionar desde los primeros algoritmos y ejercicios de código hasta trabajar con diferentes tecnologías y conceptos del desarrollo Full Stack.

---

## 🚀 Mi recorrido de aprendizaje

### 01. Fundamentos de programación

**PSeInt**

El punto de partida fue aprender a pensar como programadora y desarrollar la lógica necesaria para resolver problemas.

- Algoritmos y resolución de problemas.
- Variables y tipos de datos.
- Estructuras condicionales.
- Estructuras repetitivas.
- Pseudocódigo.
- Lógica de programación.

### 02. Backend: Java y Bases de Datos

**Java | MySQL**

Avanzamos hacia la programación utilizando Java y el trabajo con bases de datos.

- Sintaxis y estructuras del lenguaje.
- Variables, operadores y métodos.
- Condicionales y ciclos.
- Programación estructurada.
- Programación Orientada a Objetos (POO).
- Clases y objetos.
- Organización y reutilización del código.
- Bases de datos relacionales.
- Consultas SQL y gestión de información.

### 03. Frontend: Desarrollo Web

**HTML | CSS | JavaScript | React**

Incorporamos herramientas para construir interfaces y desarrollar aplicaciones web.

- Estructura de páginas con HTML.
- Diseño y estilos con CSS.
- Interactividad con JavaScript.
- Introducción a React.
- Desarrollo de interfaces web.

### 04. Integración de conocimientos: Full Stack

La formación permitió conocer distintas partes del desarrollo de software, desde la lógica y el procesamiento de datos hasta la construcción de interfaces web.

Este recorrido me permitió comprender mejor cómo se relacionan el frontend, el backend y las bases de datos dentro de una aplicación.
